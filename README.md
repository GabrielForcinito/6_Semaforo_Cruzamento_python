# 🚦 Simulação de Semáforo de Cruzamento em Python

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um exercício do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, com o objetivo de compreender e aplicar o uso da biblioteca `time` em Python.

O sistema simula o funcionamento de um **semáforo em um cruzamento**, controlando a alternância entre os sinais (verde, amarelo e vermelho) por meio de intervalos de tempo, reproduzindo o comportamento real de um trânsito.
